# Connections

> **What this is:** every external system an automation reaches, per environment — how it is reached, with what access, through which account, and where its credential is stored. Never the credential itself.
> **When it changes:** when an automation needs a system for the first time, a scope or account changes, a credential is rotated or renewed, or a system is no longer used. Entry format: `documentation-conventions` → The connections registry; how connections are chosen and held: `integrations`.
